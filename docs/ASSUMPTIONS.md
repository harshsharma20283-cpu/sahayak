# Assumptions and Limitations

## Impact formula

Estimated yearly benefit unlocked = sum over started applications of (monthly amount x 12).

- Monthly amount comes from `benefit_monthly_estimate`.
- Seed schemes have `benefit_monthly_estimate: null`, so the impact figure is 0 until verified amounts are entered.

## Demo numbers

All numbers in the demo are SAMPLE values, not official figures.

## Limitations

- Rules are placeholder values until each scheme is verified.
- Storage is a JSON file, not a database.
- The keyword fallback for extraction is basic.
- Voice input and output need Chrome or Android.
- There is no citizen login.
